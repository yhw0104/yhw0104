## 👋 About Me

> **사용자의 불편함을 먼저 찾아서 해결합니다** — 요청받은 기능을 그대로 만드는 데 그치지 않고, 어떤 구조여야 사용자가 편해지는지를 먼저 고민합니다.

의료 전산 SI 기업에서 **2년 6개월**간 Java · Spring 신규 개발과 C# · VB 기반 Windows 데스크톱(exe) 프로그램 운영을 병행하며, **200건 이상**의 현업 요구사항을 직접 분석 · 개발 · 배포했습니다.
이제는 많은 사용자가 매일 쓰는 **모바일 서비스의 백엔드**를 만들고 싶어 방향을 넓히고 있습니다.
최근에는 Spring Boot 백엔드를 중심으로 앱 · 인프라 · TestFlight 배포까지 혼자 진행한 위치 기반 소셜 앱 **혼정**을 만들었습니다.

- ⚙️ **Now** — Java · Spring Boot로 모바일 서비스 백엔드 개발
- 🍚 **Recent Project** — [**혼정 (HonJeong)**](https://github.com/yhw0104/HonJeong) : 혼밥의 심리적 장벽을 낮추는 위치 기반 식사 매칭 앱 · 1인 개발 (2026.06 ~ 2026.09)
  - REST API 80여 개 설계 · 구현 — 카카오 · Apple 로그인(JWT), 위치 기반 체크인, FCM 푸시
  - 부하 테스트로 검색 병목을 찾아 응답 시간 **669.8ms → 1.2ms**
  - 백엔드 테스트 830여 개 작성
  - Claude Code를 활용해 설계 판단과 검증(테스트 · 부하 측정)은 직접 하고 구현 속도를 높여 4개월 만에 1인 개발
